## Recommended contracts, not claims all examples implement them

- Distinguish current-state convergence from event history; first observation establishes baseline, not a new action. Scope cursors to world/connection/character and invalidate uncertain continuity.
- Emote ID changes can be stop/clear; polls can miss intermediate starts, and numeric jumps do not reconstruct commands. Native Start/Stop facts were supplied from earlier actual-binary inspection, not independently rechecked here.
- Derive stable identity through verified current platform/account binding, not player name, profile ID, ZDO origin UID or owner alone. Check actual ownership per mutation, not merely simulation-mod presence.
- Defer immutable captured values, not reusable wrappers/accessors. Native pooling implementation itself was not independently inspected in this lane.
- Snapshot streams may coalesce latest state; transient commands must have bounded explicit admission, dedup and unknown-outcome semantics. Rejection is not completion. Unknown history needs a new baseline, not fabricated replay.
- Personal exploration needs per-account cells/time and runtime geometry, not a shared map-table union. Availability and completeness must be labeled honestly.
